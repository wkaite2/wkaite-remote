安装说明

  1. 下载并安装与设备系统对应的 WKAite Remote。
  2. 打开客户端，确认设备已经在线并显示唯一 ID。
  3. 被控端设置固定密码，并在控制端输入该 ID。
  4. 连接后即可使用远程桌面、键鼠控制和文件传输。

Windows 未签名版本可能出现 SmartScreen 提示；macOS 未公证版本可能需要在“隐私与安全性”中允许打开。正式签名材料配置后此提示会消失。
